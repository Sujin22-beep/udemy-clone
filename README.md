# Udemy Clone 🎓

## 📌 Project Description

This project is a **Udemy Clone website** created using **HTML and basic CSS**. The main purpose of this project is to practice and demonstrate fundamental web development concepts by designing a simple online learning platform inspired by Udemy.

The website provides a clean and user-friendly interface for displaying online courses and learning-related content.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the web pages.
* **CSS3** – Used for styling, layout, spacing, colors, and overall appearance.

## ✨ Features

* Simple and clean Udemy-inspired user interface
* Course display section
* Navigation menu
* Responsive and organized page layout
* Basic CSS styling
* Beginner-friendly HTML structure

## 🎯 Purpose of the Project

This project was developed as a **practice project to improve my frontend web development skills**, particularly in HTML and CSS. It helped me understand webpage structure, styling, layouts, and how different HTML elements work together to create a website.
